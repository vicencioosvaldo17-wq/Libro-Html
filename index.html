SEMANA 1

Fundamentos web

SEMANA 1 · DÍA 1

HTML: estructura y contenido

Toda página web que has visitado, desde una tienda hasta una red social, empieza igual: con un archivo de texto escrito en HTML. Hoy escribirás el tuyo. No necesitas experiencia previa: solo una computadora, un editor y ganas de probar.

Qué lograrás hoy. Escribirás tu primera página web completa y sabrás explicar qué hace cada línea que escribiste.

0. Antes de empezar: cómo funciona la web

Cuando escribes una dirección en el navegador, tu computadora le pide un archivo a otra computadora (el servidor). Ese archivo llega como texto HTML, y el navegador lo lee y lo dibuja en pantalla. Por eso puedes ver el código de cualquier sitio: te lo entregaron completo.

Una página se construye con tres lenguajes, cada uno con un trabajo distinto:

LenguajeTrabajoAnalogía (una casa)
HTMLEstructura y contenidoLos planos y los muros
CSSDiseño y estiloLa pintura y la decoración
JavaScriptComportamientoLa electricidad: lo que reacciona

1. Etiquetas: el bloque básico

HTML sirve para decirle al navegador qué es cada cosa: esto es un título, esto un párrafo, esto una imagen. Una etiqueta es una palabra entre < y >. Casi siempre van en pareja: una abre y otra cierra (la de cierre lleva /). Lo que queda en medio es el contenido, y todo junto se llama elemento.

<p>Hola, soy Ana</p>
  • <p>: etiqueta de apertura. La p significa párrafo.
  • Hola, soy Ana: el contenido que verá el visitante.
  • </p>: etiqueta de cierre.
Dato útil: el navegador no se queja si escribes mal. Simplemente muestra algo raro. Por eso revisar cada cierre es un hábito que debes crear desde hoy.

2. El esqueleto de toda página

Toda página empieza igual. Memorízala; la usarás siempre.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi página</title>
</head>
<body>
  <h1>Hola, mundo</h1>
</body>
</html>
LíneaQué hace
<!DOCTYPE html>Avisa al navegador que es HTML moderno (HTML5). Siempre va primero.
<html lang="es">Abre la página completa. lang="es" indica el idioma.
<head>La "cabeza": información para el navegador que no se ve en pantalla.
<meta charset>Permite acentos, ñ y emojis. Sin esto verías símbolos raros.
<meta name="viewport">Ajusta la página al ancho del celular. Imprescindible.
<title>El texto de la pestaña del navegador.
<body>El "cuerpo": todo lo que pongas aquí se ve en pantalla.

Los espacios al inicio (sangría) no son obligatorios, pero hacen el código legible: lo que está dentro de otra etiqueta se mueve 2 espacios. Para ver tu página: guarda con Ctrl+S, clic derecho en VS Code y "Open with Live Server".

3. Textos

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Texto con <strong>negritas</strong> y <em>cursiva</em>.</p>
<br>

h1 es el título más importante: usa solo uno por página. De h2 a h6 bajan de importancia; sirven para organizar, no para "agrandar letras" (para eso está CSS). Dentro de un párrafo, strong pone negritas y em cursiva. Una etiqueta dentro de otra se llama anidación. La etiqueta br hace un salto de línea y no lleva cierre porque no tiene contenido.

Regla de anidación: cierra en orden inverso a como abriste. Correcto: <p><strong>hola</strong></p>. Incorrecto: <p><strong>hola</p></strong>.

4. Enlaces e imágenes

Aquí aparecen los atributos: datos extra dentro de la etiqueta de apertura, con la forma nombre="valor".

<a href="https://google.com" target="_blank">Ir a Google</a>
<img src="foto.jpg" alt="Mi perro Max" width="300">
  • href: la dirección de destino del enlace.
  • target="_blank": abre el enlace en una pestaña nueva.
  • src: el nombre del archivo de la imagen (debe estar en tu carpeta).
  • alt: descripción por si la imagen no carga y para lectores de pantalla. Ponla siempre.
  • width: ancho en píxeles. img no lleva cierre.

5. Listas

<ul>
  <li>Pan</li>
  <li>Leche</li>
</ul>

ul abre una lista con viñetas (unordered list) y cada elemento va en un li (list item). Si usas ol en vez de ul, la lista se numera sola.

6. Etiquetas semánticas

Son cajas con nombre que indican la función de cada zona: header (cabecera), nav (menú de enlaces), main (contenido principal), section (sección) y footer (pie). Se ven igual que un div, pero ordenan tu código y ayudan a buscadores y lectores de pantalla.

<header><h1>Ana López</h1></header>
<main>
  <section>
    <h2>Quién soy</h2>
    <p>Estudiante de sistemas.</p>
  </section>
</main>
<footer><p>2026</p></footer>

7. Formularios

Un formulario recoge datos del visitante. label es el texto visible, input el campo de una línea (su type define qué acepta: text, email, password…), textarea la caja grande y button el botón. El for del label debe ser igual al id del campo: así, al tocar el texto se selecciona el campo.

Errores comunes: olvidar cerrar una etiqueta, no guardar antes de recargar y escribir mal el nombre de la imagen. Si no carga, revisa nombre, extensión (¿.jpg o .jpeg?) y que esté en la misma carpeta que index.html.

SEMANA 1 · DÍA 2

CSS: colores, tipografía y diseño

Ayer escribiste el contenido. Hoy le das diseño. CSS (Cascading Style Sheets, hojas de estilo en cascada) no cambia lo que dice la página, solo cómo se ve: colores, letras, espacios y posición.

Qué lograrás hoy: separar el diseño del contenido, escribir reglas CSS, usar selectores, entender el modelo de caja y darle estilo completo a tu página.

1. Tres formas de poner CSS

La forma profesional es un archivo externo: un solo CSS le da estilo a todas tus páginas. Se enlaza dentro del head:

<link rel="stylesheet" href="estilos.css">

También existen el bloque <style> dentro del head (útil para pruebas rápidas) y el atributo style="color:red" dentro de una etiqueta (evítalo: mezcla diseño y contenido y es difícil de mantener). Usaremos siempre el archivo externo.

2. Anatomía de una regla

h1{
  color:#1456d9;
  font-size:2rem;
}
  • Selector (h1): a qué elementos se aplica.
  • Propiedad (color): qué quieres cambiar.
  • Valor (#1456d9): cómo lo quieres.

Cada declaración termina en punto y coma. Los comentarios se escriben /* así */. Si olvidas un ; o una llave, esa regla (y a veces las siguientes) deja de funcionar.

3. Selectores

SelectorEjemploElige
EtiquetapTodos los párrafos
Clase.tarjetaElementos con class="tarjeta" (reutilizable)
Id#menuUn único elemento con id="menu"
Grupoh1, h2Varios selectores a la vez
Descendientenav aLos a dentro de un nav
Estadoa:hoverEl enlace cuando pasas el cursor

Regla práctica: usa clases para casi todo; el id déjalo para identificar un elemento único (por ejemplo, para JavaScript).

4. Colores y unidades

Un color se puede escribir por nombre (blue), en hexadecimal (#1456d9: rojo, verde y azul en pares de dígitos) o como rgb(20,86,217). Con rgba(...,0.5) agregas transparencia.

Las unidades de tamaño más usadas: px (píxeles, fijo), rem (relativo al tamaño base de letra: 1rem suele ser 16px; ideal para textos y espacios), % (relativo al contenedor) y vh (porcentaje del alto de la pantalla).

5. Texto y fondos

body{
  font-family:Georgia,serif;  /* con respaldo */
  font-size:1rem;
  line-height:1.6;            /* altura de línea */
  color:#10223d;
  background:#ffffff;
}
h1{text-align:center;font-weight:800}

font-family acepta varias fuentes: si falla la primera, usa la siguiente. Termina siempre con serif o sans-serif. Un line-height entre 1.5 y 1.7 hace el texto cómodo de leer.

6. El modelo de caja

Todo elemento es una caja con cuatro capas, de adentro hacia afuera: contenido, padding (espacio interior), border (borde) y margin (espacio exterior).

.tarjeta{
  padding:16px;                 /* aire dentro */
  border:2px solid #1456d9;
  border-radius:12px;           /* esquinas redondas */
  margin:16px 0;                /* arriba/abajo 16, lados 0 */
}
*{box-sizing:border-box}        /* el ancho incluye padding y borde */

Con margin:16px 0 el primer valor es arriba y abajo, el segundo izquierda y derecha. Con cuatro valores el orden es arriba, derecha, abajo, izquierda (como las manecillas del reloj). Agrega siempre box-sizing:border-box: evita que las cajas se hagan más anchas de lo esperado. Para centrar una caja con ancho fijo usa margin:0 auto.

7. La cascada: quién gana

Si dos reglas chocan, gana la más específica (id > clase > etiqueta); si empatan, gana la que está más abajo. Además, algunas propiedades (color, fuente) se heredan: si pones font-family en body, todo el texto la usa.

Errores comunes: no enlazar bien el archivo (revisa el nombre y que esté en la misma carpeta); escribir colour en lugar de color; olvidar el punto en .clase; y no recargar con Ctrl+F5 cuando el navegador guardó una versión vieja. Para investigar, haz clic derecho, "Inspeccionar" y revisa qué reglas se aplican.

Flexbox y diseño para celular

Hasta ahora todo se apila hacia abajo. Hoy aprenderás a ponerlo en fila, centrado y repartido, y a que se adapte a cualquier pantalla. Más de la mitad de las visitas web vienen de celulares, así que diseñar para ellos no es opcional.

Qué lograrás hoy: usar Flexbox para acomodar elementos, hacer un diseño que cambie en celular con @media y entender las unidades flexibles.

1. La idea de Flexbox

Flexbox trabaja con un contenedor (el padre) y sus elementos (los hijos directos). Activas el modo con display:flex en el contenedor y los hijos se colocan en una línea.

<div class="fila">
  <div>Uno</div>
  <div>Dos</div>
  <div>Tres</div>
</div>
.fila{display:flex;gap:12px}

gap separa los elementos sin necesidad de márgenes.

2. Los dos ejes

Flexbox tiene un eje principal (por defecto horizontal) y un eje cruzado (vertical). flex-direction:column los intercambia: el eje principal pasa a ser vertical. Entender esto evita la confusión más común.

PropiedadControlaValores útiles
flex-directionDirección del eje principalrow, column
justify-contentReparto en el eje principalflex-start, center, space-between, space-around
align-itemsAlineación en el eje cruzadostretch, center, flex-start
flex-wrapSi pasan a otra líneanowrap, wrap

3. Centrar todo (el truco clásico)

.centro{
  display:flex;
  justify-content:center;   /* horizontal */
  align-items:center;       /* vertical */
  min-height:100vh;
}

4. Cómo crecen los elementos: flex

La propiedad flex de un hijo resume tres valores: grow (cuánto crece si sobra espacio), shrink (cuánto se encoge si falta) y basis (tamaño ideal).

.fila{display:flex;gap:12px;flex-wrap:wrap}
.fila > div{flex:1 1 200px}  /* ideal 200px, crece y se encoge */

Con flex-wrap:wrap las tarjetas bajan de línea cuando no caben: es un diseño adaptable sin escribir más reglas.

5. Diseño para celular (responsive)

Primero, confirma que tu head tenga <meta name="viewport" content="width=device-width, initial-scale=1.0">; sin esa línea el celular dibuja la página como si fuera de computadora y la encoge. Luego usa media queries: reglas que solo se activan bajo una condición.

/* diseño base: pensado para celular */
.fila{flex-direction:column}

/* a partir de 700px de ancho, en fila */
@media (min-width:700px){
  .fila{flex-direction:row}
}

Esta estrategia se llama mobile first: escribes primero lo del celular y vas agregando mejoras para pantallas grandes con min-width. Dos reglas más para un diseño sano: img{max-width:100%;height:auto} (las imágenes nunca se salen) y usar rem o % en vez de píxeles fijos.

Errores comunes: poner display:flex en el elemento equivocado (debe ir en el padre); olvidar flex-wrap y ver todo apretado; ver la página bien en computadora pero mal en celular por faltar la etiqueta viewport. Prueba abriendo F12 y activando el icono de celular.

SEMANA 1 · DÍA 4

JavaScript: lógica de programación

HTML es el contenido, CSS el diseño y JavaScript es el cerebro: toma decisiones, repite tareas y reacciona. Hoy aprendes su lógica base, que es la misma en casi todos los lenguajes de programación.

Qué lograrás hoy: guardar datos en variables, tomar decisiones con if, repetir con ciclos y reutilizar código con funciones.

1. Dónde escribirlo y cómo ver resultados

Puedes escribirlo en un archivo script.js enlazado antes de cerrar el body, con <script src="script.js"></script>. Para ver resultados usa console.log() y abre la consola con F12 (pestaña Console). Es tu mejor herramienta para entender qué hace tu código.

2. Variables y tipos de datos

Una variable es una caja con nombre que guarda un dato. const se usa cuando el valor no cambiará; let cuando sí.

const nombre = 'Ana';   // texto (string)
let edad = 18;          // número (number)
let activo = true;      // verdadero o falso (boolean)
edad = edad + 1;        // cambia el valor
console.log(`Hola ${nombre}, tienes ${edad}`);

Las comillas invertidas (`) permiten insertar variables con ${...}. Los nombres no llevan espacios ni empiezan con número, y se escriben en camelCase (miNombre).

3. Operadores

TipoOperadores
Aritméticos+ - * / % (el % da el residuo)
Comparación=== !== > < >= <=
Lógicos&& (y), || (o), ! (no)
Cuidado: = asigna y === compara. Confundirlos es el error de principiante más común. Usa siempre ===.

4. Decisiones: if / else

let nota = 8;
if (nota >= 9) {
  console.log('Excelente');
} else if (nota >= 7) {
  console.log('Aprobado');
} else {
  console.log('Reprobado');
}

JavaScript revisa las condiciones en orden y ejecuta solo el primer bloque que sea verdadero.

5. Repetición: ciclos

// for: cuando sabes cuántas veces
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// while: mientras se cumpla una condición
let n = 3;
while (n > 0) { console.log(n); n--; }

El for tiene tres partes: inicio (let i = 1), condición (i <= 5) y paso (i++, suma 1). Si la condición nunca se vuelve falsa, el ciclo no termina (ciclo infinito): revisa siempre que algo cambie.

6. Funciones

Una función es un bloque de pasos con nombre. Recibe parámetros, hace algo y puede devolver un resultado con return.

function promedio(a, b, c) {
  return (a + b + c) / 3;
}
console.log(promedio(8, 9, 10)); // 9

7. Arreglos: primer vistazo

const colores = ['rojo', 'azul'];
colores.push('verde');          // agrega
console.log(colores[0]);        // 'rojo' (se cuenta desde 0)
console.log(colores.length);    // 3
Errores comunes: olvidar un paréntesis o llave; escribir Console.log con mayúscula; usar una variable antes de declararla; y llamar una función sin paréntesis (promedio en lugar de promedio(8,9,10)). El mensaje rojo de la consola siempre te dice la línea del error.

Ejercicios en clase

    Ver solución

  • Escribe una función que diga si un número es par.
    Ver solución

SEMANA 1 · DÍA 5

JavaScript en la página: botones y eventos

Ya sabes la lógica de JavaScript. Hoy la conectas con tu página: harás que los botones respondan, que el texto cambie y que un formulario se lea. Aquí es donde la web se vuelve interactiva.

Qué lograrás hoy: seleccionar elementos con el DOM, cambiar su contenido y estilo, y reaccionar a clics y escritura con eventos.

1. El DOM: tu página convertida en objetos

Cuando el navegador lee tu HTML, construye un árbol de objetos llamado DOM (Document Object Model): html contiene a head y body, y así sucesivamente. JavaScript puede buscar cualquier elemento de ese árbol, leerlo y modificarlo, y el cambio se ve al instante.

2. Seleccionar elementos

const titulo = document.getElementById('titulo');   // por id
const boton  = document.querySelector('.boton');      // primero que coincida (selector CSS)
const items  = document.querySelectorAll('li');       // todos los que coincidan

querySelector usa la misma sintaxis de selectores de CSS (.clase, #id, etiqueta), por eso es la más cómoda.

3. Cambiar contenido, estilo y clases

titulo.textContent = 'Nuevo título';        // cambia el texto
titulo.style.color = 'blue';                 // cambia un estilo
titulo.classList.add('destacado');           // agrega una clase
titulo.classList.toggle('oscuro');           // la pone o quita
imagen.src = 'otra.jpg';                     // cambia un atributo

Lo mejor es crear la apariencia en CSS con una clase y solo activarla con classList; así el diseño sigue en el CSS y JavaScript solo decide cuándo usarlo.

4. Eventos

Un evento es algo que ocurre: un clic, escribir, enviar un formulario. Con addEventListener indicas qué evento escuchar y qué función ejecutar.

boton.addEventListener('click', () => {
  titulo.textContent = '¡Hiciste clic!';
});
EventoCuándo ocurre
clickAl hacer clic o tocar
inputCada vez que cambia lo escrito en un campo
submitAl enviar un formulario
mouseoverAl pasar el cursor encima

5. Leer lo que escribe el usuario

<input id="nombre" placeholder="Tu nombre">
<button id="saludar">Saludar</button>
<p id="resultado"></p>
<script>
  const campo = document.getElementById('nombre');
  const salida = document.getElementById('resultado');
  document.getElementById('saludar').addEventListener('click', () => {
    const nombre = campo.value.trim();   // .value lee, .trim() quita espacios
    salida.textContent = nombre ? `Hola, ${nombre}` : 'Escribe tu nombre';
  });
</script>

6. Formularios y preventDefault

Por defecto, un formulario recarga la página al enviarse. Con evento.preventDefault() detienes eso y manejas los datos tú:

formulario.addEventListener('submit', (e) => {
  e.preventDefault();
  console.log(campo.value);
});

7. Mini aplicación: contador

let cuenta = 0;
const numero = document.getElementById('numero');
document.getElementById('mas').addEventListener('click', () => {
  cuenta++;
  numero.textContent = cuenta;
});

Observa el patrón que se repite en toda aplicación: un dato (variable) → un evento del usuario → se actualiza el dato → se actualiza la pantalla.

Errores comunes: poner el script antes del HTML (el elemento aún no existe y obtienes null: colócalo al final del body); escribir mal el id; usar innerHTML con texto del usuario (riesgo de seguridad: prefiere textContent); y olvidar que .value siempre devuelve texto, aunque escriban un número.

Ejercicios en clase

    Ver solución

  • Botón que active y desactive el modo oscuro.
    Ver solución
    boton.addEventListener('click',()=>document.body.classList.toggle('oscuro'));

SEMANA 8 · DÍA 1

Panel de administración

Idea central

Un panel de administración permite ver y gestionar todos los datos, y solo debe estar disponible para el rol admin.

Ejemplo

if(rol==='admin')cargarTodo();else location='inicio.html';

Ejercicios en clase

  • Lista todos los usuarios.
    Ver solución
    select * en perfiles, solo para admin.
  • Botón para eliminar un registro.
    Ver solución
    await db.from('registros').delete().eq('id',id);

Tarea

  • Haz un panel con listado y una acción.

SEMANA 8 · DÍA 2

Pulido y responsive final

Idea central

Pulir es revisar espacios, textos y mensajes, y comprobar que todo se vea bien en cualquier pantalla.

Ejemplo

@media (max-width:600px){main{padding:12px}}

Ejercicios en clase

  • Revisa en 3 tamaños de pantalla.
    Ver solución
    Celular, tableta y computadora.
  • Unifica los textos de botones y mensajes.
    Ver solución
    Mismo tono en todo el proyecto.

Tarea

  • Entrega una lista de 10 mejoras visuales aplicadas.

SEMANA 8 · DÍA 3

Despliegue con Firebase Hosting

Idea central

Firebase Hosting publica tu página con dominio y HTTPS gratis.

Ejemplo

npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy

Ejercicios en clase

  • Inicializa Hosting en tu carpeta.
    Ver solución
    firebase init hosting
  • Publica y abre el enlace.
    Ver solución
    firebase deploy

Tarea

  • Deja el proyecto final en línea.

SEMANA 8 · DÍA 4

Documentación y portafolio

Idea central

Un buen README explica qué hace tu proyecto, cómo usarlo y qué tecnologías usa. Es tu portafolio.

Ejemplo

# Mi proyecto
## Qué hace
## Tecnologías
## Cómo usarlo

Ejercicios en clase

  • Escribe el README.
    Ver solución
    Usa la estructura de arriba.
  • Agrega 3 capturas.
    Ver solución
    Una por cada pantalla principal.

Tarea

  • Arma un portafolio con 3 proyectos del curso.
